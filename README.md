# 网页用户备注助手

为网页中的用户添加自定义备注，并自动渲染到昵称旁。包含两个版本：

| 目录 | 版本 | 说明 |
|---|---|---|
| `v1-local/` | 本地版 | Chrome 扩展，数据保存在 `chrome.storage.local`，无需后端 |
| `v2-sqlite/` | SQLite 同步版 | Chrome 扩展 + Python + SQLite 后端，数据可用 DB Browser / DBeaver 管理，支持统计 |

> 非官方开源工具，与知乎及任何网站官方无关。仅用于用户个人浏览时本地标注，不提供抓取、上传或商业化服务。

## 功能

- 在网页用户昵称旁显示自定义备注
- 支持标签库、下拉搜索、多选、回车新增
- 用户主页昵称旁、回答/评论作者旁自动渲染
- 用户名旁「备注」按钮，点击即可编辑
- 导入 / 导出数据
- v2 额外支持：SQLite 数据库、统计页面（用户量 / 备注量 / 每日新增走势 / 来源）

## 快速开始

### v1 本地版

1. 打开 `chrome://extensions`
2. 开启「开发者模式」
3. 加载已解压的扩展程序 → 选择 `v1-local/`

### v2 SQLite 版

1. 启动后端：
   ```bash
   cd v2-sqlite/backend
   python app.py
   ```
2. 加载扩展：`chrome://extensions` → 加载已解压 → 选择 `v2-sqlite/extension/`
3. 扩展设置里确认后端地址 `http://127.0.0.1:8000`
4. 统计页面：http://127.0.0.1:8000/stats

## 技术说明

- 用户标识优先使用真实 `uid`（知乎页面数据 / 埋点中的 `id`），`url_token` 仅作兜底
- 纯 DOM 操作，不调用网站接口
- v2 数据保存在 SQLite（`v2-sqlite/backend/data/zhihu-tagger.db`），可用数据库工具直接管理
